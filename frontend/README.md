# Roomify — frontend

React 19 + Vite + Tailwind 4 + React Query 5 SPA for the Roomify marketplace.

See the [root README](../README.md) for setup, environment variables and the
overall architecture.

```bash
cp .env.example .env.local
npm install
npm run dev      # http://localhost:5173
```

| Script | Purpose |
|---|---|
| `npm run dev` | Vite dev server |
| `npm run build` | production bundle to `dist/` |
| `npm run lint` | ESLint |
| `npm test` | node:test unit suite |
